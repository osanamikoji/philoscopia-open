Personal utility / 個人用ツール

GitHubDriveSync

GitHubDriveSync は、管理者本人が所有する GitHub リポジトリの最新ファイルを、本人の Google ドライブにバックアップ・参照用として保存する個人用ツールです。

主な機能

  • GitHub リポジトリのファイルを ZIP 形式で Google ドライブに保存
  • 検索・参照しやすいテキスト索引を作成
  • 前回の記録と比較して変更のないリポジトリをスキップ
  • 管理者が手動実行、または設定した時刻に自動実行

GitHub が元データの正本です。Google ドライブ上のファイルは参照用のコピーであり、このウェブサイトで公開されることはありません。

Google ドライブとの連携

管理者本人の許可を得て Google Drive API を使用し、専用フォルダ内のファイルの作成、一覧確認、更新および転送後の検証を行います。OAuth によるアクセス許可は管理者本人が設定・解除できます。

プライバシーポリシー / Privacy Policy 利用条件 / Terms

GitHubDriveSync is a personal utility that copies current files from the owner's GitHub repositories to the owner's Google Drive for backup and reference. GitHub remains the authoritative source. This informational website does not publish repository contents or Drive files.
