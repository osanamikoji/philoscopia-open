GitHubDriveSync

プライバシーポリシー

GitHubDriveSync は、管理者本人の GitHub リポジトリから Google ドライブへデータを同期する個人用ツールです。

1. 取り扱うデータ

Google OAuth の認証情報、Google ドライブ上の同期先フォルダとそのファイルの情報、同期結果の記録を取り扱います。認証に使用する OAuth 権限は Google Drive の広範なファイル操作を許可するものですが、同期プログラムは管理者が指定した専用フォルダを同期先とします。

2. 利用目的

GitHub のファイルを ZIP と参照用テキストに変換して保存し、前回の同期結果と照合し、転送内容を検証するためだけに利用します。

3. 保存と共有

同期ファイルは管理者本人の Google ドライブに保存します。同期作業は GitHub Actions 上で実行されます。OAuth 認証情報は GitHub Actions の Secrets に保管し、公開ページには掲載しません。データの販売、広告目的での利用、一般公開は行いません。サービス実行に必要な Google および GitHub の基盤を利用します。

4. 保持期間と削除

作成された同期ファイルと記録は、管理者が Google ドライブから削除するまで保持されます。管理者は Google アカウントの連携設定からアプリのアクセスを取り消すことができます。

5. この公開ページ

このページは説明のための静的なウェブサイトで、独自のアクセス解析、広告、入力フォームは設けていません。公開ページのホスティングには GitHub Pages を利用します。

Privacy Policy (English summary)

GitHubDriveSync is a personal tool for copying the owner's GitHub repository files to the owner's Google Drive. It uses Google Drive OAuth authorization to create, list, read, verify, and update files for syncing in a designated folder. The OAuth scope permits broad Drive access, but the sync code targets the designated folder.

Repository archives, text indexes, and sync records remain in the owner's Google Drive; this website does not publish them. The sync runs on GitHub Actions, with OAuth credentials stored in GitHub Actions Secrets. The tool does not sell, advertise with, or intentionally disclose user data publicly. Google and GitHub infrastructure are used to operate the tool.

Copies and records remain until the owner deletes them; the owner can revoke Google account access. This static site has no proprietary analytics, ads, or collection forms. For contact, see the linked GitHub profile.
