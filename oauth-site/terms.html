GitHubDriveSync

利用条件

GitHubDriveSync は管理者本人が利用する個人用同期ツールです。一般向けの登録サービスやデータ配布サービスではありません。

利用者は、アクセス権限を有する GitHub リポジトリと Google ドライブについてのみ同期を実行します。GitHub が正本であり、同期先のコピーは参照・バックアップ補助を目的とします。

同期処理はネットワーク、API、認証状態などによって中断することがあります。重要なデータについては元の GitHub リポジトリを確認してください。

Terms (English summary)

This is a personal, owner-operated utility, not a public signup or data distribution service. The operator uses it only with repositories and Drive accounts they are authorized to access. GitHub remains the source of truth. Transfers may fail or be interrupted; verify important data against GitHub.
